# JD_poster

Poster for [Jacobian Descent for Multi-Objective Optimization](https://arxiv.org/abs/2406.16232),
the method implemented in [TorchJD](https://github.com/SimplexLab/TorchJD).

## Building

```bash
latexmk -pdf main.tex
```

Requires a TeX Live installation with `tcolorbox`, `sourcesanspro` and `qrcode`.
